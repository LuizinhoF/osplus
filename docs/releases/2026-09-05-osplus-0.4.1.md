## What's in this build

- Optional Home Hub update notification with a quiet sound, brief animation,
  English/pt-BR text, and a click through to the matching GitHub release.
- Pregame chat presence hides opponents until gameplay is observed. Old clients
  stay restricted until updated; chat message audiences are unchanged.
- Relay release metadata and recipient-specific presence filtering deployed
  before publishing the client package.

Implementation commits: `09bd218` (notification), `dc578e1` (chat privacy),
`8bbdf6e` (version, bilingual notes, release-helper UTF-8 notes support).

## Known caveats and recovery

- In-game phase timing remains unverified; follow the
  [maintainer's test checklist](../learnings/chat-pregame-presence-privacy.md#verification-and-remaining-check).
  Unknown/unreadable state remains restricted rather than exposing opponents.
- Older clients cannot signal gameplay disclosure and remain teammate-only
  throughout a match until updated; unknown-team clients and spectators are
  self-only. A mod started mid-intermission may wait for the next observed
  gameplay phase. This is client-reported state, not an anti-cheat boundary.
- Prior local ZIP and pak retained at
  `%LOCALAPPDATA%/OSPlus/dev-backups/release-0.4.1-fa534551-1e20-44d6-a51f-f8f2cbcc4ac5/`.
- Predeployment VM code/Caddy/service backup:
  `/opt/osplus/backups/relay-pre-v0.4.1-20260905.tar.gz`.
  Database data and node_modules were excluded; deployment made no schema change.
- The earlier local test relay was not restarted or stopped. The installed mod
  now uses production, so that local instance is no longer part of this test setup.
